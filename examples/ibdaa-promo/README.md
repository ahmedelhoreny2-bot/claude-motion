# إبداع بيتحرك: إعلان ترويجي (60 ثانية، 9:16)

**البرومبت:** إعلان دعائي مدته دقيقة لصفحة جرافيك موشن اسمها «إبداع بيتحرك»، أنيميشن 2.5D مع مؤثرات صوتية وفويس أوفر بالمصري، وهوك قوي، ونهاية فيها «شغالين في كل المجالات» ودعوة للتواصل على الواتساب ورسايل الصفحة.

**الفكرة:** «وقّف السكرول». المثلث البرتقالي من اللوجو بيوقّف فيد الإعلانات الثابتة، ويصحّي كومة الإعلانات المنسية بخبطة، وبعدها بيعرض أنواع الشغل. الخطوط التلاتة في اللوجو هي اللي بتعمل كل الانتقالات، وفي الآخر بتتحول لفقاعات شات للتواصل.

- الكومبوزيشن: `IbdaaPromo` (1080×1920، 30fps)، والكود في `src/promo/`
- التايم لاين: `src/promo/timeline.json`
- الصوت: `sfx/cues/promo.py` → `public/promo-music.wav` (عند ‎-16 LUFS عشان يفضل مكان للفويس)

## الدمج بعد تسجيل الفويس

```bash
ffmpeg -y -i out/ibdaa-silent.mp4 -i public/promo-music.wav -i public/promo-vo.wav \
  -filter_complex "[2:a]loudnorm=I=-16:TP=-1.5,asplit=2[vo][sc];[1:a][sc]sidechaincompress=threshold=0.05:ratio=6:attack=20:release=300[duck];[duck][vo]amix=inputs=2:normalize=0,loudnorm=I=-14:TP=-1[a]" \
  -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 256k -movflags +faststart out/ibdaa-promo.mp4
```
